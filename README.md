# YAN — Portfolio

Portfolio pribadi, dibangun dengan HTML/CSS/JS, React untuk kartu pengenal interaktif, dan canvas untuk animasi lanyard.

## Isi

- **Home** — kartu pengenal interaktif yang bisa digerakkan dan dibalik
- **About** — background, minat, dan hal-hal yang sedang dikerjakan
- **Portfolio** — proyek, sertifikat, pencapaian, dan tech stack
- **Contact** — form pesan (membuka email) + tautan sosial

## Menjalankan di lokal

Tinggal buka `index.html` di browser. Tidak perlu build step atau install dependency.

Untuk serve cepat lewat HTTP:

```bash
python -m http.server 8000
# lalu buka http://localhost:8000
```

## Struktur

```
├── index.html          # satu file utama (HTML + CSS + JS)
└── assets/             # aset: gambar, SVG, dan runtime JS
```

## Teknologi

- HTML5, CSS3 (custom properties, CSS grid/flex)
- JavaScript vanilla
- SVG untuk ilustrasi & ikon
- Komponen kartu 3D kecil dengan canvas
